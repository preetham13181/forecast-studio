# Forecast Studio
Streamlit app: upload any time series (or use sample sales / a Yahoo Finance ticker), forecast with Prophet, SARIMAX or naive baselines, backtest against baselines, tune ARIMA with AIC/BIC, and convert the band into an order quantity.

Run locally: install requirements.txt, then `streamlit run app.py`.
Deploy: push this folder to a public GitHub repo, then pick the repo and app.py on share.streamlit.io.
